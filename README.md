# DiffChecker — Desktop App

A fast, local, side-by-side diff checker built with Electron.  
**No internet required. No data ever leaves your machine.**

---

## ✨ Features

- Side-by-side diff view with line numbers
- Character-level highlighting on changed lines
- Toggle between **Full File** and **Changes Only** views
- Expandable collapsed hunks (GitHub-style)
- Load any file from disk (JS, TS, CSS, HTML, Python, XML, JSON, Markdown…)
- Swap panels instantly
- Scroll-synced panels
- Native app menu with keyboard shortcuts
- Works fully offline

---

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18 or higher
- npm (comes with Node.js)

### Install & Run

```bash
# 1. Install dependencies
npm install

# 2. Launch the app
npm start
```

---

## 📦 Build a Windows Installer (.exe)

```bash
npm run build:win
```

This produces two files inside the `dist/` folder:
- `DiffChecker Setup 1.0.0.exe` — standard NSIS installer (adds to Start Menu + Desktop)
- `DiffChecker 1.0.0.exe` — portable single `.exe`, no install needed

### Build for other platforms

```bash
npm run build:mac    # macOS .dmg
npm run build:linux  # Linux .AppImage
```

> **Note:** To build for Windows from macOS/Linux you need Wine installed,  
> or use a Windows machine / GitHub Actions CI.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+Enter` | Run Compare |

| `Ctrl+Shift+S` | Swap Panels |
| `Ctrl+1` | Full File View |
| `Ctrl+2` | Changes Only View |
| `F11` | Toggle Fullscreen |
| `Ctrl+Shift+I` | Developer Tools |

## 🗂 Project Structure

```
diffchecker-app/
├── main.js        ← Electron main process (window, menu, shortcuts)
├── preload.js     ← Secure bridge between main and renderer
├── index.html     ← The entire UI (self-contained)
├── package.json   ← Dependencies and build config
├── build/
│   ├── icon.ico   ← Windows icon (add your own)
│   ├── icon.icns  ← macOS icon (add your own)
│   └── icon.png   ← Linux icon (add your own, 512×512px)
└── dist/          ← Built outputs (generated by electron-builder)
```

---

## 🖼 Adding a Custom Icon

Place your icon files in the `build/` folder:
- `icon.ico` for Windows (256×256 recommended)
- `icon.icns` for macOS
- `icon.png` for Linux (512×512px)

You can convert a PNG to ICO using [icoconvert.com](https://icoconvert.com) or ImageMagick:
```bash
magick icon.png -resize 256x256 build/icon.ico
```
